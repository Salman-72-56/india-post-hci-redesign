How This Prototype Fixes Real HCI Flaws

Direct comparison between indiapost.gov.in legacy design and human-centered design principles.

#1

CAPTCHA Barrier Eliminated

Legacy: Required solving a mathematical CAPTCHA (e.g. 7 - 2 = ?) for routine package tracking, causing high abandonment.

HCI Solution: Zero CAPTCHA for standard queries with client-side regex format checking and automated rate limiting.

#2

Plain Human Mental Model

Legacy: Outputted dense technical tables with abbreviations like "Item Dispatched to NSH New Delhi DPT".

HCI Solution: Visual progression stepper with plain English/vernacular status: "In Transit • Sorting Center".

#3

Direct PIN Code Retrieval

Legacy: Required selecting State -> District -> Postal Division across 4 sequential page refreshes.

HCI Solution: Single fuzzy search bar with instant autocomplete and direct delivery capability indicators.
